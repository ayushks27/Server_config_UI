## Getting Started

It’s a dedicated server setup designed to manage tool configurations and streamline service integration. The UI guides users through creating and customizing their own MCP (Managed Configuration Point) server with a clean and intuitive multi-step form. From naming the server to selecting tools and finalizing setup, everything happens within a smooth, modern interface built with Tailwind’s utility-first styling.

First, run the development server:

```bash
npm run dev
# or
yarn dev
# or
pnpm dev
# or
bun dev
```
now you are ready to go: bun run dev || npm run dev
